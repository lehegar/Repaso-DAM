# Repaso DAM - Verano

Repositorio de ejercicios prácticos de Java y SQL realizados durante el verano 
para repasar y consolidar el contenido del primer año de DAM.

## Estructura del proyecto

### 01-Java-Basico
Ejercicios de sintaxis y estructuras básicas de Java.

- **AdivinaElNumero** — bucles, Random, Scanner, contadores
- **Calculadora** — switch, operadores, validación de entrada
- **Contrasena** — Strings, Character, booleanos como flags
- **PiedraPapelTijera** — bucles, switch, lógica de juego
- **GestorNotas** — ArrayList, menús, CRUD básico

### 02-POO
Programación orientada a objetos aplicada.

- **Clase Producto** — atributos privados, constructor, getters y setters
- **Tienda** — composición, ArrayList de objetos, búsquedas
- **Vehiculo** — herencia, extends, super, @Override
- **Interfaces Polimorfismo** — interfaces, implements, polimorfismo
- **Biblioteca** — mini proyecto integrador de POO

### 03-Colecciones y excepciones
Estructuras de datos avanzadas y manejo de errores.

- **Agenda** — HashMap, operaciones clave-valor
- **ManejoExcepciones** — try/catch, NumberFormatException, IndexOutOfBoundsException
- **Ficheros** — FileWriter, BufferedReader, persistencia en ficheros .txt

### 04-SQL (próximamente)
Consultas SQL con Oracle Database.

- Diseño de modelo relacional
- SELECT, WHERE, ORDER BY
- JOINs entre tablas
- GROUP BY y HAVING
- Proyecto SQL: base de datos de tienda

### 05-Proyecto Final (próximamente)
Aplicación Java con base de datos integrada.

- Diseño de clases
- Conexión Java + SQL (JDBC)
- Operaciones CRUD completas

## Tecnologías

- Java 25
- Oracle Database Free (Docker)
- Git y GitHub
- VS Code

## Objetivo

Llegar preparada al segundo año de DAM con una base sólida y práctica 
de programación Java y bases de datos relacionales.
